# Lovable UI source reference

This folder preserves the supplied Lovable React/Tailwind `src/` package for design reference.
The production Streamlit entrypoint is `app.py`. The visual concept was migrated into native Streamlit components and
`styles/lovable_streamlit.css`, with `assets/dashboard-banner.jpg` reused as the dashboard hero artwork.

The React files in this folder are **not required** by Streamlit Community Cloud and are intentionally kept separate from the Python runtime.
